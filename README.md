#### 💓 PulseSync *(in progress)*
**AI-powered fitness &amp; adaptive music app**

A closed-loop fitness system: **Body → AI → Music → Body response → Learning.**

- React Native + Expo + TypeScript mobile app (iOS &amp; Android)
- Live **Fitbit** heart rate via Google OAuth 2.0 + Google Health API
- Heart-rate-driven adaptive music with the **Spotify Web API** (energy tiers based on HR level *and* trend)
- Node.js / Express backend for auth, tokens and health data
- Next up: auto rest timer, recovery &amp; fatigue insights, personal "Workout DNA", AI Coach
